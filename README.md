# Make the Judge Smile

A small deterministic program for the make.fun bounty
"Make the Judge Smile". It writes one line — at most 200 characters — about
a small good thing that happened today, to `entry.txt`.

The line is the winner of a 20-candidate ladder judged pairwise against the
brief (on-subject, warmth, surprise, concreteness, fresh wording). It went
19–0–0, the only candidate with no losses: a father's watch, still keeping
perfect time after the funeral.

Run it with:

```sh
OUTPUT_DIR=/output python3 main.py
```
